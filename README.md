# Task2_EDA
# Task 2: Exploratory Data Analysis (EDA)

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) using the Titanic dataset. The objective is to understand data through descriptive statistics, visualizations, and pattern identification.

## Tools and Libraries
- Python
- Pandas
- Matplotlib
- Seaborn

## Dataset
Titanic passenger dataset containing information such as age, gender, passenger class, fare, and survival status.

## Tasks Performed

1. Loaded and explored the Titanic dataset.
2. Examined dataset dimensions, data types, and statistical summaries.
3. Identified missing values in different columns.
4. Visualized missing values using a heatmap.
5. Created histograms to understand numerical feature distributions.
6. Generated a correlation matrix and heatmap.
7. Analyzed survival rates based on gender.
8. Compared survival rates across passenger classes.
9. Examined survival rates across child and adult age groups, excluding missing ages.

## Visualizations

- Missing Values Heatmap
- Numerical Feature Histograms
- Correlation Heatmap

## Key Findings

- Female passengers had a higher survival rate than male passengers.
- First-class passengers had a higher survival rate than third-class passengers.
- Children had a higher observed survival rate than adults.
- Passenger fare had a positively skewed distribution.
- Passenger class and survival showed a negative correlation.
